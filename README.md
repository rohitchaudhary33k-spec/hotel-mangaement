# Hotel Management System

A simple Java-based Hotel Management System for managing hotel rooms and guest bookings.

## Features

- View all rooms
- Book a room
- Search for a room
- Check out a guest
- View room availability
- Store guest booking information

## Technologies Used

- Java
- OOP
- ArrayList
- Scanner
- Methods
- Conditional Statements
- Loops

## How to Run

1. Clone or download this repository.
2. Open the project in VS Code.
3. Open the terminal.
4. Compile the program:

```bash
javac HotelManagement.java
